# 🛡️ موقع أمانك — Safe Guard

موقع ويب ثابت (HTML/CSS/JS) لتطبيق حماية الأطفال "أمانك"، نسخة مطابقة من التصميم الأصلي مع إضافات جاهزة.

---

## 📁 محتويات المجلد

```
amanak-website/
├── index.html            ← الصفحة الرئيسية (البطل + الأقسام + الفيديو + الخصوصية)
├── app-safety.html       ← صفحة التطبيقات الآمنة والخطرة (بحث + فلاتر)
├── child-monitor.html    ← صفحة حماية طفلك (ربط الأجهزة + التنبيهات)
├── camera.html           ← صفحة كاميرا المراقبة (تشغيل + مايك + صوت)
├── css/
│   └── style.css         ← ملف التصميم الكامل (الألوان والهوية)
├── js/
│   └── main.js           ← ملف التفاعلات (البحث، التنبيهات، الكاميرا، مشغل الفيديو، المعرض)
├── fonts/                ← خط Tajawal محلياً (يعمل بدون إنترنت)
├── images/               ← الصور التوضيحية + ملصق الفيديو + باركود QR
├── media/                ← 🎬 فيديو أمانك التعريفي (1080p + 720p + ملف ترجمة)
└── README.md             ← هذا الملف
```

---

## 🚀 طريقة الاستخدام

### 1) فتح الموقع محلياً
اضغط مرتين على ملف `index.html` وسيفتح الموقع في المتصفح مباشرة — لا يحتاج إنترنت أو أي برنامج.

### 2) رفع الموقع على استضافة
ارفع **كل محتويات المجلد** كما هي إلى أي استضافة ثابتة:
- **Netlify** (الأسهل): اسحب المجلد وأفلته في netlify.com/drop
- **Vercel**: عبر حسابك أو `vercel deploy`
- **GitHub Pages**: ارفع الملفات لمستودع وفعّل Pages
- أي استضافة عربية (لينوفه، هوستنجر...) عبر FTP

## 🎨 تغيير الألوان والهوية

كل الألوان معرّفة كمتغيرات في أعلى ملف `css/style.css`:

```css
:root {
  --primary: #4F41D6;     /* اللون البنفسجي الأساسي */
  --accent: #0EA5E9;      /* الأزرق السماوي */
  --background: #F5F7F9;  /* لون الخلفية */
  --emerald: #10B981;     /* أخضر الآمن */
  --red: #EF4444;         /* أحمر الخطورة */
}
```

غيّر أي لون هنا وسيتغير في الموقع كله تلقائياً.

الصور التوضيحية جاهزة في مجلد `images/`، ولتعرضها في الصفحات ستجد في كل صفحة كوداً معلّقاً (بين `<!-- -->`) جاهزاً — فقط احذف علامات التعليق:

## 🎬 فيديو أمانك التعريفي (جديد!)

أصبح قسم الفيديو في الصفحة الرئيسية **مشغّل فيديو حقيقياً**:

- **فيديو مدمج** مدته ~68 ثانية بتعليق صوتي عربي (صوت رجالي سعودي واضح)
- **7 مشاهد**: مقدمة، دليل التطبيقات، حماية طفل، كاميرا المراقبة، الخصوصية، خطوات البدء، الختام
- **يعمل بدون إنترنت** — الملفات في مجلد `media/`
- **خيارات المشغل**:
  - الجودة: `1080p` أو `720p خفيف` (بتبديل يحفظ موضع المشاهدة)
  - السرعة: `0.75× / عادي / 1.25× / 1.5×`
  - الترجمة النصية العربية: زر «إظهار النص»
  - تكرار تلقائي + زر تحميل الفيديو
- **معرض صور** أسفل الفيديو: 6 صور توضيحية مع عارض مكبّر (تنقّل بالأسهم ولوحة المفاتيح)

### ملفات الفيديو:
| الملف | الوصف | الحجم |
|-------|-------|-------|
| `media/amanak-intro-1080p.mp4` | الجودة العالية | ~12 MB |
| `media/amanak-intro-720p.mp4` | نسخة خفيفة | ~5 MB |
| `media/amanak-intro-ar.vtt` | ملف الترجمة (مرجعي) | 1 KB |

### تغيير نص التعليق أو التوقيتات:
نصوص الترجمة وتوقيتاتها موجودة في `js/main.js` داخل المصفوفة `AMANAK_SUBS` — عدّلها بحرية.
إن أردت **استبدال الفيديو بفيديو آخر** ضع ملفك باسم `amanak-intro-1080p.mp4` (و720p) في مجلد `media/`.

### رابط يوتيوب والباركود:
الباركود المعروض في بطاقة الفيديو ما زال يشير إلى رابط **تجريبي** على يوتيوب.
عند رفع فيديوك الحقيقي على يوتيوب:

1. افتح `js/main.js` وغيّر قيمة `AMANAK_VIDEO_URL` في الأعلى.
2. أعد توليد الباركود (انظر القسم التالي) واستبدل `images/qr-video.png`.

> 💡 يمكنك أيضاً رفع فيديو أمانك المدمج (`media/amanak-intro-1080p.mp4`) نفسه على قناتك في يوتيوب واستخدامه كفيديو الشرح الرسمي.

## 📱 توليد باركود QR لرابطك الجديد

### الطريقة السهلة (بدون برمجة):
1. اذهب إلى أي موقع توليد باركود مثل `qr-code-generator.com` أو `the-qrcode-generator.com`
2. الصق رابط الفيديو
3. حمّل الصورة وسمّها `qr-video.png`
4. استبدل الملف القديم في مجلد `images/`

### الطريقة البرمجية (اختياري):
إذا عندك Python ثبّت المكتبة وشغّل السكربت المرفق `make-qr.py`:
```bash
pip install qrcode pillow
python3 make-qr.py
```
عدّل قيمة `VIDEO_URL` داخل السكربت قبل التشغيل.

## ✏️ تعديل المحتوى

### إضافة تطبيق جديد (صفحة التطبيقات):
انسخ أي بطاقة `<div class="app-card safe">...</div>` وغيّر:
- الإيموجي والاسم والتصنيف والوصف
- خاصية `data-app` (تُستخدم في البحث)
- خاصية `data-type` إما `safe` أو `danger`

### إضافة تنبيه جديد (صفحة حماية طفلك):
انسخ أي بطاقة `<div class="alert-card">` وغيّر الاسم والدرجة والوصف. زر "إضافة تنبيه تجريبي" يعمل تلقائياً.

### تعديل نصوص الرأس:
كل النصوص ظاهرة مباشرة في ملفات HTML — افتح الملف بأي محرر نصوص وعدّل.

## 🌐 ملاحظات تقنية

- الموقع **متجاوب** بالكامل (جوال، تابلت، كمبيوتر)
- اتجاه الصفحات RTL (من اليمين لليسار) للغة العربية
- الخط Tajawal محمّل محلياً من مجلد `fonts/` — لا حاجة للإنترنت
- لا توجد مكتبات خارجية — HTML/CSS/JS نقي فقط
- حجم الموقع (بدون الفيديو) أقل من 1 ميجابايت — وملفات الفيديو ~17 MB في مجلد media منفصل
